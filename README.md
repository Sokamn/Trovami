Trovami is a social job marketplace Android application focused on connecting people who need help with people looking for small jobs and income opportunities.

The application was designed to make it easier for users to find quick local jobs such as:
- House cleaning
- Painting
- Plumbing
- Babysitting
- Electrical work
- PC technical support
- Masonry
- And more

> Developed as a personal Android project with a strong social impact focus.

---

# 💡 Motivation

The main inspiration behind Trovami was my mother, who works cleaning homes and constantly needed to find new job opportunities.

That led me to think:

> “There should be an app that helps people find small jobs quickly and easily.”

Trovami was created to help both sides:
- People who need help solving problems
- People looking for work opportunities and extra income

The name comes from Italian:

- **Trova** → Find
- **Trovami** → Find me

---

# 📱 Features

- 📌 Publish job opportunities
- 💬 Real-time chat between users
- 👤 User profiles
- ⭐ Rating system after job completion
- 🔎 Search with filters
- 🗂️ Job categories
- 📍 Location integration
- 🔐 Authentication with Google & Email
- 🖼️ Profile images and job-related media

---

# ⚙️ How It Works

1. A user publishes a job request
2. Another user accepts the job
3. Both users gain access to a private chat
4. They coordinate the work details
5. Once completed, both users can rate each other

The goal was to create a simple and accessible workflow focused on fast local jobs and community support.
